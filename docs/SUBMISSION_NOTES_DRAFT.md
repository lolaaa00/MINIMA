# Submission notes draft

MINIMA is a reusable least-privilege primitive for data-aware agents and contracts. A controller seals a public field catalogue and an exact purpose, requester, consumer and TTL. A requester then commits an action hash before GenLayer consensus classifies every declared field as NECESSARY, NOT_NECESSARY or AMBIGUOUS. Validators independently recompute the economically meaningful NECESSARY and AMBIGUOUS masks. Deterministic code rejects incomplete/malformed classifications, refuses every ambiguous request, and issues a permit containing exactly the necessary field bitmask. The permit is pinned to schema hash, purpose hash, requester, consumer, action hash and expiry; purpose/permit revocation invalidates it. MINIMA never stores private field values and does not claim legal compliance. See the finalized 61999 lifecycle in DEPLOYMENT.md before submission.
