PRODUCT / PRIMITIVE GOAL
MINIMA is a standalone reusable Intelligent Contract primitive for field-level data minimisation. It must never store private customer data. A data controller publishes only a schema catalogue (field names/descriptions/sensitivity labels), freezes a purpose, authorised requester, consumer and TTL, and then an authorised requester commits an action hash. GenLayer validators independently classify every declared field as NECESSARY, NOT_NECESSARY or AMBIGUOUS for that exact frozen purpose. Deterministic contract logic rejects malformed/incomplete/duplicate field classifications, fails closed if any field is ambiguous, and otherwise issues a permit containing exactly the NECESSARY field mask.

THE CENTRAL SECURITY INVARIANT
`permit.field_mask` must be derived solely from the consensus-backed necessary mask. There must be no caller argument, owner override, admin method, post-resolution edit, consumer preference or UI setting that can expand it.
